# Project overview

This repository is a dependency-free static website for AADFC. Keep the existing
HTML, CSS, and JavaScript structure; no build step is required.

## Run on Replit

Start the site with:

```sh
python3 -m http.server 5000 --bind 0.0.0.0
```

The Replit workflow named `Start application` runs this command and exposes the
site in the web preview.
